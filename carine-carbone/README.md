# Carine Carbone Estética

Landing page estática (HTML, CSS e JS puros), sem build.

## Editar
- Número do WhatsApp: constante `CONFIG.whatsapp` no fim do `index.html` (formato `55` + DDD + número, só dígitos).
- Textos: procure por "(exemplo)" no `index.html` e troque pelo conteúdo real.
- Fotos: coloque os arquivos na pasta `img/` e troque os blocos `.ill` pelas tags `<img>`.

## Publicar na Vercel
Importe este repositório em vercel.com/new. Framework: Other. Sem comando de build e sem pasta de saída.
